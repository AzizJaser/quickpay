# OWASP ASVS Level 1 — self-assessment (Phase 9 close-out)

- **Date:** 2026-09-24
- **Scope:** the six chapters the Phase 9 plan named — V2 auth, V3 session, V4 access control,
  V5 validation & injection, V7 errors & logging, V14 configuration.
- **Rating:** **0** absent · **1** partial · **2** built, unverified · **3** built + evidence.
  A rating with no evidence pointer is challenged down to 0 (Phase 9 rule).
- **A rating is not a grade.** This is a four-service learning system with **one deliberately
  unbuilt control (5B, service auth)** and **no HTTPS by design in dev**. Low scores in V2/V14
  are *recorded decisions*, not oversights — see ADR-0006 and §Accepted risk below.

> This scorecard covers the **customer-facing** surface (customer-service BFF + wallet money
> path). The three simulators and the gateway HMAC path are out of ASVS scope here.

## Score

Counting the 30 rated lines above (max 3 each = 90):

```
V2  auth            2+3+3+0+1+0          =  9 / 18
V3  session         3+3+3+1+2+0+0        = 12 / 21
V4  access control  3+2+3+0+3            = 11 / 15
V5  validation      3+3+1+2              =  9 / 12
V7  errors/logging  2+3+2+3             = 10 / 12
V14 configuration   1+3+1+0              =  5 / 12
                                    TOTAL = 56 / 90
```

**ASVS-L1 self-rating: 56 / 90.**

The gap is concentrated and *named*, not diffuse: **V2 and V14** carry the deferred service-auth
decision (5B) and the dev-only posture (no TLS, committed dev creds, exposed ports). Both are
recorded sponsor decisions with triggers, not gaps discovered here. The money path's own
access control (V4) and session integrity (V3) are the strongest columns — which is the correct
shape for a system whose thesis is *money is never created or destroyed*.

## Accepted risk (declared, per THREAT_MODEL §6)

no HTTPS (dev) · no rate limiting incl. `/login` · dev credentials committed · no audit trail
of session use · four DB ports + broker UI reachable from host · **5B service auth deferred
(hole measured, `A04` §6)** · step-up auth designed not built (ADR-0006).
